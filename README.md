# jakeshake's Unraid templates

Container templates for Unraid Community Applications.

| App | Template | Project |
|---|---|---|
| Pinebridge MT5 | [pinebridge-mt5.xml](pinebridge-mt5.xml) | [jakeshake/pinebridge](https://github.com/jakeshake/pinebridge) |
| Pinebridge Bridge | [pinebridge-bridge.xml](pinebridge-bridge.xml) | [jakeshake/pinebridge](https://github.com/jakeshake/pinebridge) |
| Wordly | [wordly.xml](wordly.xml) | [jakeshake/wordly](https://github.com/jakeshake/wordly) |

Install them from the **Apps** tab in Unraid. Issues with an app go to that app's project repo.
